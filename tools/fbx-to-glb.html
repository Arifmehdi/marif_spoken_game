Convert an FBX prop into a game-ready GLB

Nothing in a browser or in Node reads FBX, so the conversion happens here, with the same three.js loader the game already ships. Each prop is stripped of anything that is not geometry, centred on X/Z with its base on y = 0, and scaled to the height the game expects. The result goes back to the props folder as <name>_raw.glb; npm run build:props then cuts the triangle count and compresses it.
